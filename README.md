# 📊 Marketing Campaign Performance Dashboard | Excel

## 📌 Project Overview

This project focuses on analyzing marketing campaign performance using Microsoft Excel. The objective is to transform raw marketing data into an interactive dashboard that helps businesses evaluate campaign effectiveness, advertising costs, customer engagement, and return on investment (ROI).

The dashboard allows users to explore campaign performance across different companies, marketing channels, locations, languages, and customer segments.

## 🎯 Business Objectives

- Evaluate marketing campaign performance.
- Identify companies with higher marketing ROI.
- Compare conversion rates across different locations.
- Analyze acquisition costs across geographic regions.
- Understand clicks and impressions across campaign types.
- Evaluate ROI across marketing channels and target audiences.
- Support data-driven marketing decisions.

## 📂 Dataset Information

**Dataset:** Marketing Campaign Performance Dataset  
**Source:** Kaggle  
**Format:** CSV  

### Dataset Columns

| Column | Description |
|---|---|
| Company | Company running the campaign |
| Campaign_Type | Type of marketing campaign |
| Target_Audience | Intended customer group |
| Duration | Campaign duration |
| Channel_Used | Marketing channel |
| Conversion_Rate | Campaign conversion effectiveness |
| Acquisition_Cost | Cost of acquiring customers |
| ROI | Return on Investment |
| Location | Campaign location |
| Language | Campaign language |
| Clicks | Number of advertisement clicks |
| Impressions | Number of advertisement displays |
| Engagement_Score | Audience engagement measurement |
| Customer_Segment | Customer classification |
| Date | Campaign date |

## 📈 Key Performance Indicators (KPIs)

The dashboard includes the following KPIs:

1. Average Conversion Rate
2. Total Acquisition Cost
3. Total Clicks
4. Total Impressions
5. Average ROI
6. Total Campaign Records

## 📊 Dashboard Visualizations

The dashboard provides the following analytical views:

- Conversion Rate by Location
- Acquisition Cost by Location
- ROI by Marketing Channel
- ROI by Location
- Clicks and Impressions by Campaign Type
- ROI by Target Audience

## 🎛️ Interactive Features

The dashboard includes interactive slicers for:

- Company
- Language
- Location

These filters allow users to explore campaign performance from different perspectives.

## 💡 Business Value

This project demonstrates how raw marketing data can be transformed into meaningful business insights.

It helps management understand campaign performance, compare marketing channels, monitor acquisition costs, and identify opportunities to improve marketing effectiveness.
